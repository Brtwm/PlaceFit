## Validation method

Renderer-level Markdown artifacts were generated from schema-valid API fixtures
and deterministic fixture-derived snapshots using only
`render_analysis_markdown(response)` and `export_compare_markdown(response)`.
The renderers did not call backend endpoints, providers, databases, analysis,
scoring, finance, confidence, decision, report generation, fallback generation,
LLMs, saved-session loading, or compare ranking.

Temporary artifacts were inspected as UTF-8 text and removed after acceptance.
The owner subsequently completed Docker reset/smoke, Streamlit download, and
external-file opening checks for all required scenarios and reported `PASS`.
The owner also completed 45 previously deferred manual validation cases and
reported all 45 as `PASS`. Detailed per-case sheets are not committed; this
document records the aggregate owner confirmation only.

## Explicit checks

- Required analysis and compare sections were present in stable order.
- `expected_gross_income_by_user` is labeled as a user hypothesis, not a
  PlaceFit/system forecast.
- Profit and manual-verification disclaimers are visible.
- Export adds no unsupported competitor, traffic, revenue, recommendation, or
  compliance facts.
- Score, confidence, decision, finance, ranking order, and ranking rules match
  their source snapshots.
- Failed candidates and supported ambiguous suggestions remain visible.
- Marketplace checks remain manual guidance, not official compliance.
- Existing fallback report text is included only when already present in the
  source snapshot and is not regenerated.
- PlaceFit does not guarantee profit.
