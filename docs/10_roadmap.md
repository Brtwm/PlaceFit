# Roadmap — PlaceFit

## MVP (Version 1.0)

**Цель**: Рабочий сервис для оценки одного адреса под ПВЗ в Краснодаре.

- Геокодинг адреса
- Поиск и дедупликация конкурентов (300/500/700 м)
- Rule-based scoring 0–100
- Confidence score 0–100
- Финансовая модель (break-even, payback)
- Базовая проверка требований маркетплейсов
- AI-отчёт из JSON + fallback
- Чек-лист ручной проверки
- История анализов
- Карта с конкурентами
- Scoring versioning на уровне БД (`scoring_versions`, `scoring_version_id`)
- Docker Compose
- Unit tests (scoring, finance)

---

## V1.5 — Сравнение и мониторинг

**Цель**: Превратить из калькулятора одной точки в инструмент принятия решений.

- Сравнение 2–5 адресов (compare mode)
- Улучшенный confidence score
- UI/admin-механизм управления версиями скоринга
- Сравнение результатов между версиями скоринга
- История изменения правил скоринга
- Улучшенный модуль маркетплейсов (реальные правила Ozon/WB/YM)
- Telegram-бот (быстрый анализ)
- Экспорт PDF / Excel
- Мониторинг сохранённых адресов
- Улучшение карты и фильтров
- Competitor strength score (рейтинг, отзывы)

---

## V2 — Location Intelligence

**Цель**: От анализа адреса к поиску перспективных зон.

- City-wide search по H3-гексагонам
- Тепловая карта перспективности
- Trendwatcher (сигналы: новые ЖК, закрытие конкурентов, отзывы)
- Infrastructure intelligence
- Мониторинг изменений конкурентов
- Расширение на кофейни, сервисные точки
- Геоаналитика спроса (плотность, трафик)
- React/Next.js frontend

---

## V3 (Final) — ML и B2B платформа

**Цель**: Полноценная B2B location intelligence платформа.

- ML-прогноз выручки/заказов/окупаемости (CatBoost/LightGBM)
- Поддержка 10+ типов бизнеса (аптеки, цветы, зоомагазины и др.)
- Отдельные scoring profiles для каждого бизнеса
- Backtesting на исторических данных
- Оптимизация сети точек, прогноз каннибализации
- API для интеграции с CRM/BI
- Дашборды для инвестора
- Авторизация и ролевая модель доступа
- Production monitoring и observability

---

## Что НЕ делать раньше времени

| Фича | Почему не раньше |
|------|-----------------|
| ML-прогноз | Нет обучающей выборки до V3 |
| H3/heatmap | Требует массовых данных, V2 |
| Trendwatcher | Нет источников данных, V2 |
| Парсинг Авито/Циан | Юридические риски, никогда без легальной основы |
| Browser-agent | Не соответствует архитектуре |
| Мобильное приложение | Нет в roadmap |
